# numpy-stats-calculator
The program defines a function calculate() that:  Accepts a list of 9 numeric values.  Converts the list into a 3×3 NumPy array.  Returns a dictionary containing the mean, variance, standard deviation, max, min, and sum for each axis (0 &amp; 1) and for the flattened matrix.  Raises a ValueError if the input list has fewer than 9 elements
